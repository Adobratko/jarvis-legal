Jarvis Dashboard

Jarvis Dashboard is a private, non-commercial desktop application that runs locally on its developer's own computer. It shows the statistics of the developer's own social media accounts in a personal dashboard.

TikTok integration

The app uses TikTok Login Kit for Desktop and the Display API with read-only access. After the account owner logs in and grants permission, it shows follower count, following count, total likes, video count and the counts of views, likes, comments and shares for the owner's own videos. It does not post or change any content and does not access data of other users.
