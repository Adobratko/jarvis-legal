Jarvis Dashboard - Privacy Policy

Last updated: 11 October 2026

1. About this app

Jarvis Dashboard is a private, non-commercial application that runs locally on the personal computer of its developer. It displays statistics of the developer's own TikTok account in a personal dashboard. It is not offered to the public and has no other users.

2. Data we access

After the account owner logs in with TikTok and grants permission, the app reads only the following data of that same account through the TikTok Display API:

  • Basic profile information (display name, avatar) to show which account is connected (user.info.basic)
  • Account statistics: follower count, following count, total likes and video count (user.info.stats)
  • The list of the account owner's own videos with view, like, comment and share counts (video.list)

The app has read-only access. It does not post, edit or delete content and does not access direct messages or any data of other TikTok users.

3. How data is used and stored

The data is used only to display statistics in the local dashboard. Access tokens are stored in a local configuration file on the developer's computer. Statistics are kept in memory and are not transmitted to any server operated by the developer or by third parties.

4. Sharing

We do not sell, share or disclose any data to third parties. Data is exchanged only between the local application and TikTok.

5. Retention and deletion

Tokens are kept until the account owner revokes access. Access can be revoked at any time in the TikTok app under Settings and privacy, Security and permissions, Manage app permissions, or by deleting the token from the local configuration file. After revocation the app can no longer access any data.

6. Contact

Questions about this policy can be sent through the TikTok account that registered this app.

7. Changes

This policy may be updated. The date above shows the latest version.
